# Template Vault

`templates/vault/` is a **fictional** Primee Vault, shipped with the repository
so you can see the memory model before you create your own.

Everything in it is invented: the "Lighthouse project", the kickoff call, the
teams and the disagreement about pilot length do not exist. It contains no real
person, company, account, message or conversation, and it is not derived from
anyone's data.

It exists to demonstrate:

- one raw note (`raw/`) — immutable captured material;
- one wiki topic (`wiki/`) linked back to that raw note, with facts,
  interpretations and an unresolved conflict kept apart;
- one dated output (`outputs/`) linked to the wiki topic;
- a valid `INDEX.md`, `CHANGELOG.md` and `PRIMEE.md`;
- a `wiki/plan-candidates` page in the shape the `plan` skill expects.

## This is not your Vault

Your real Vault lives on your own computer, outside this repository, at a path
you configure (`[vault] root`, or the `PRIMEE_VAULT_PATH` environment
variable). It is never committed, pushed or published — see `.gitignore` and
`docs/memory.md`.

Do not point Primee at this folder and start using it as real memory. Create
your own with:

```
python run_primee.py vault init --root "<your absolute path>" --dry-run
```

## Regenerating

The template is generated by Primee itself, so it always matches the current
schema. The tests in `tests/test_template_vault.py` verify that it stays valid,
that every page parses, that every wikilink resolves, and that its `INDEX.md`
matches a fresh rebuild byte for byte.
